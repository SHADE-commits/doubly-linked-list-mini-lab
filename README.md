# Doubly Linked List Mini Lab

Tugas Data Structures: Doubly Linked List dengan insert, delete, forward traversal, dan backward traversal (C++).

Nama: Nayla Novtiera Anjani

## Cara compile dan run
g++ src/main.cpp -o program
./program

## Fitur
- Node dengan data, prev, dan next
- Forward traversal (next) dan backward traversal (prev)
- Insert di tengah (Song X di antara Song B dan Song C)
- Delete node (Song C)
- Contoh dunia nyata: browser history (experiments/browser_history.cpp)
- Prediksi vs hasil aktual dan break and fix (folder experiments)
- Screenshot hasil program (folder screenshots)
